# Third-party components

ZynqRadio uses or interoperates with the following external projects. Their respective licenses apply to those components.

- **libiio** — Analog Devices IIO userspace library, loaded dynamically at runtime.
- **NAudio 2.2.1** — Windows audio access from .NET.
- **WSJT-X** — external digital-mode application used for CAT/audio integration testing.
- **Hamlib protocol** — ZynqRadio implements the NET rigctl protocol expected by WSJT-X.
- **VB-Audio Virtual Cable / Voicemeeter** — optional external audio-routing software used in the demonstrated Windows setup.

No SoapySDR API is used by ZynqRadio.
