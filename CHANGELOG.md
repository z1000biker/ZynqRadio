# Changelog

## [1.0.0] - 2026-09-02

First public release.

### Added
- Windows GUI for radio, DSP, audio, CAT and diagnostics.
- Direct libiio control of Zynq-7000 + AD936x hardware without SoapySDR.
- Hamlib NET rigctl compatible CAT endpoint for WSJT-X.
- Full-duplex RX/TX path with 48 kHz Windows audio integration.
- Gapless FT8 TX FIFO and diagnostic WAV capture.
- I-only low-bandwidth RX transport for stable simultaneous full-duplex operation.
- Proven FT8 self-reception and decode at 1296.174 MHz in the development setup.
